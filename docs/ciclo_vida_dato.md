# 3.4 Ciclo de vida del dato aplicado

## Introducción

El ciclo de vida del dato permite comprender las diferentes etapas por
las que pasa un dato desde que se identifica una necesidad de información
hasta que los resultados obtenidos se utilizan para tomar una decisión.

Las principales etapas consideradas en este ejercicio son: pregunta,
fuente, exploración, calidad, análisis, comunicación y acción.

## 1. Etapas del ciclo de vida del dato

| Etapa | Descripción |
| --- | --- |
| **Pregunta** | Se define qué se quiere conocer o qué problema se necesita resolver. |
| **Fuente** | Se identifican los lugares o sistemas de donde se obtendrán los datos. |
| **Exploración** | Se revisan y conocen los datos disponibles para identificar patrones o características iniciales. |
| **Calidad** | Se comprueba que los datos sean completos, correctos, consistentes y confiables. |
| **Análisis** | Se aplican técnicas para obtener información y encontrar relaciones o patrones. |
| **Comunicación** | Se presentan los resultados de forma clara mediante informes, tablas, gráficos o conclusiones. |
| **Acción** | Se utilizan los resultados para tomar decisiones y realizar acciones de mejora. |

## 2. Caso aplicado: seguimiento académico

Para aplicar el ciclo de vida del dato se utilizará como ejemplo el
seguimiento académico de los aprendices.

### Pregunta

¿Qué aprendices presentan dificultades académicas que requieren
acompañamiento formativo?

### Fuente

Los datos pueden obtenerse de registros de asistencia, actividades
realizadas, evidencias entregadas, calificaciones y observaciones de
los instructores.

### Exploración

Se revisan los datos disponibles para conocer la asistencia, el
promedio de actividades, las evidencias entregadas y las observaciones
registradas para cada aprendiz.

### Calidad

Se verifica que los registros estén completos y que no existan datos
duplicados, valores incorrectos o información inconsistente.

También se revisa que los porcentajes y promedios se encuentren dentro
de rangos válidos.

### Análisis

Se pueden comparar variables como asistencia, promedio de actividades y
cantidad de evidencias entregadas para identificar aprendices que
presenten dificultades.

Por ejemplo, un aprendiz con baja asistencia, pocas evidencias
entregadas y un promedio bajo podría requerir mayor acompañamiento.

### Comunicación

Los resultados pueden presentarse mediante una tabla, un informe o una
visualización sencilla que permita identificar las principales
situaciones encontradas.

La información debe comunicarse de forma clara y evitando exponer datos
personales innecesarios.

### Acción

Con los resultados obtenidos se pueden establecer acciones de
acompañamiento, orientación y seguimiento para los aprendices que
presenten dificultades.

## 3. Importancia de la calidad de los datos

La calidad de los datos es fundamental porque las decisiones dependen de
la información obtenida a partir de ellos.

Si los datos contienen errores, duplicados o información incompleta, el
análisis puede producir resultados incorrectos y llevar a tomar
decisiones inadecuadas.

Por esta razón, antes de analizar los datos es necesario revisar,
limpiar y validar la información disponible.

## 4. Ética y privacidad

El análisis de información académica debe realizarse de manera
responsable. Los datos personales deben protegerse y utilizarse
únicamente para los fines necesarios.

Los resultados deben comunicarse evitando exponer información sensible
o identificar innecesariamente a los aprendices.

También es importante utilizar información confiable y evitar
interpretaciones que puedan generar conclusiones injustificadas.

## 5. Reflexión

El ciclo de vida del dato permite comprender que analizar información no
consiste únicamente en utilizar una herramienta tecnológica. Primero es
necesario definir una pregunta, identificar fuentes confiables, revisar
la calidad de los datos y posteriormente realizar el análisis.

Aplicar este proceso de manera ordenada permite obtener resultados más
confiables y tomar decisiones fundamentadas en información.

## Conclusión

El ciclo de vida del dato proporciona una guía para transformar datos
en información útil para la toma de decisiones. Cada etapa cumple una
función importante y debe desarrollarse de manera responsable.

En el caso del seguimiento académico, este proceso puede ayudar a
identificar dificultades, generar estrategias de acompañamiento y
mejorar el seguimiento de los aprendices.

# 3.8 Cierre y socialización técnica

## Introducción

Durante esta actividad se desarrolló un primer acercamiento al proceso
de trabajo con datos utilizando Python. Se realizaron actividades de
reflexión, diagnóstico, análisis del ciclo de vida del dato y planteamiento
de un caso integrador.

También se configuró un ambiente reproducible y se realizó una
verificación mediante un script de Python.

## 1. Aprendizajes obtenidos

Durante el desarrollo de la actividad aprendí que los datos pueden
utilizarse para obtener información útil y apoyar la toma de decisiones.

También comprendí la importancia de:

- Organizar correctamente los datos.
- Revisar la calidad de la información.
- Definir preguntas antes de realizar un análisis.
- Utilizar herramientas adecuadas para procesar datos.
- Mantener un ambiente de trabajo reproducible.
- Proteger los datos personales.
- Utilizar la información de manera ética y responsable.

## 2. Herramientas utilizadas

Para preparar el ambiente de trabajo se utilizaron las siguientes
herramientas:

| Herramienta | Utilidad |
| --- | --- |
| **Python** | Lenguaje utilizado para trabajar con datos. |
| **pandas** | Permite organizar y analizar conjuntos de datos. |
| **NumPy** | Permite realizar operaciones numéricas. |
| **Jupyter** | Permite trabajar con notebooks para análisis de datos. |
| **openpyxl** | Permite trabajar con archivos de Excel. |
| **Faker** | Permite generar datos ficticios para pruebas. |
| **VS Code** | Entorno utilizado para desarrollar el proyecto. |

## 3. Verificación del ambiente

Se creó un entorno virtual denominado `.venv` para mantener separadas
las dependencias del proyecto.

También se creó el archivo `requirements.txt`, que permite registrar las
versiones de las herramientas instaladas.

Finalmente, se ejecutó el script `verificar_entorno.py`, mediante el cual
se comprobó el funcionamiento de Python, las bibliotecas instaladas y
las carpetas principales del proyecto.

## 4. Reflexión sobre ética y privacidad

El trabajo con datos requiere responsabilidad, especialmente cuando se
maneja información relacionada con personas.

Los datos personales deben utilizarse únicamente cuando sean necesarios
y deben protegerse frente a accesos o usos no autorizados.

Además, los resultados obtenidos mediante el análisis de datos deben
interpretarse correctamente y no utilizarse para generar conclusiones
injustificadas o discriminatorias.

## 5. Reflexión final

La actividad permitió comprender que la ciencia de datos no consiste
solamente en utilizar herramientas de programación. También es necesario
comprender el problema, formular preguntas, revisar la calidad de los
datos y utilizar los resultados de manera responsable.

La configuración del ambiente reproducible constituye una base
importante para continuar desarrollando actividades de análisis de datos
con Python.

## Conclusión

El desarrollo de esta actividad permitió establecer una base para
continuar aprendiendo ciencia de datos con Python.

Se comprendió la importancia del ciclo de vida del dato, la calidad de
la información, la configuración de ambientes reproducibles y el uso
ético de los datos.

Estos conocimientos servirán como punto de partida para desarrollar
posteriormente procesos de limpieza, análisis y visualización de datos.

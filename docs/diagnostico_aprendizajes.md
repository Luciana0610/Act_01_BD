# 3.2 Diagnóstico de aprendizajes previos

## Introducción

Esta actividad permite identificar los conocimientos previos sobre
datos, tipos de datos, fuentes de información, calidad de los datos,
herramientas para su análisis y aspectos relacionados con la privacidad
y el uso responsable de la información.

## 1. ¿Qué es un dato?

Un dato es un valor, hecho o registro que representa una característica
de una persona, objeto, situación o proceso. Los datos pueden presentarse
como números, textos, fechas, imágenes u otros formatos.

## 2. ¿Qué es un conjunto de datos?

Un conjunto de datos es una colección organizada de datos relacionados
entre sí. Por ejemplo, una tabla con información de aprendices puede
contener datos como identificación, asistencia, calificaciones y
actividades realizadas.

## 3. ¿Qué es un archivo CSV?

Un archivo CSV (Comma-Separated Values) es un archivo de texto utilizado
para almacenar información organizada en filas y columnas. Los valores
normalmente están separados por comas y puede ser utilizado para
intercambiar datos entre diferentes programas.

## 4. ¿Qué representan las filas y las columnas?

Las filas representan registros o elementos individuales de un conjunto
de datos.

Las columnas representan las características o variables de esos
registros.

Por ejemplo, en una tabla de aprendices, cada fila puede representar a
un aprendiz y cada columna puede representar su nombre, asistencia o
promedio.

## 5. ¿Qué tipos de datos conozco?

Algunos tipos de datos comunes son:

- Texto: nombres, ciudades o descripciones.
- Enteros: cantidades sin decimales.
- Decimales: valores que contienen números decimales.
- Booleanos: valores verdadero o falso.
- Fechas: información relacionada con días, meses y años.

## 6. ¿Qué fuentes de datos conozco?

Algunas fuentes de datos pueden ser:

- Archivos CSV.
- Hojas de cálculo.
- Bases de datos.
- Formularios.
- Aplicaciones.
- Sensores.
- Sistemas empresariales.
- Encuestas.

## 7. ¿Por qué es importante la calidad de los datos?

La calidad de los datos es importante porque permite realizar análisis
más confiables y tomar mejores decisiones. Los datos incompletos,
duplicados, incorrectos o desactualizados pueden generar resultados
equivocados.

## 8. ¿Qué problemas pueden existir en un conjunto de datos?

Algunos problemas frecuentes son:

- Datos faltantes.
- Registros duplicados.
- Valores incorrectos.
- Diferentes formatos para un mismo dato.
- Datos desactualizados.
- Errores de digitación.
- Información inconsistente.

## 9. ¿Qué herramientas conozco para trabajar con datos?

Conozco herramientas como Microsoft Excel, Google Sheets y Python.
Python permite utilizar bibliotecas especializadas como pandas y numpy
para organizar, analizar y procesar datos.

## 10. ¿Por qué es importante proteger los datos personales?

Es importante proteger los datos personales para evitar usos indebidos,
pérdidas, accesos no autorizados o vulneraciones de la privacidad.

Cuando se trabaja con información personal se debe utilizar únicamente
la información necesaria y aplicar medidas responsables para protegerla.

## 11. ¿Qué espero aprender en el curso?

Espero aprender a recolectar, organizar, limpiar, analizar y visualizar
datos utilizando Python. También espero comprender cómo utilizar los
datos de manera responsable para obtener información útil y apoyar la
toma de decisiones.
